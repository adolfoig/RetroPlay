1. Descargar el proyecto
2. Habrir la terminal e ir a la la carpeta de server que esta dentro del proyecto y poner: node server.js, aparecerá un mensaje diciendo "Servidor corriendo en el puerto 3000".
3. Abrir Android Studio e ir a app/java/com.example.retroplay/JugarJuegoFragment y ahí dentro cambiar el private String IP por la ip de su equipo.
4. Dentro de Android Studio ir a app/res/assets/classic-tetris-js-master/classic-tetris.js y cambiar el cont ip con la ip de su equipo.
5. Dentro de Android Studio ir a app/res/assets/flappy-bird-master/main-js y cambiar el cont ip con la ip de su equipo.
6. Dentro de Android Studio ir a app/res/assets/pacman/pacman.js y cambiar el cont ip con la ip de su equipo.
7. Ejecutar el programa.
