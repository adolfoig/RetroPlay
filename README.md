1. Descargar el proyecto
2. Abrir la terminal e ir a la la carpeta de server que esta dentro del proyecto y poner: node server.js, aparecerá un mensaje diciendo "Servidor corriendo en el puerto 3000".
3. Abrir la terminal y escribir en windows "ipconfig" y en ubuntu "ifconfig" y copiar la direccion IPv4
4. Abrir Android Studio e ir a app/java/com.example.retroplay/Repository/JuegosRepository.java y ahí dentro cambiar el private String IP por la ip que copió anteriormente.
5. Dentro de Android Studio ir a app/res/assets/classic-tetris-js-master/classic-tetris.js y cambiar el cont ip por la ip que copió anteriormente.
6. Dentro de Android Studio ir a app/res/assets/flappy-bird-master/main-js y cambiar el cont ip por la que copió anteriormente.
7. Dentro de Android Studio ir a app/res/assets/pacman/pacman.js y cambiar el cont ip por la que copió anteriormente.
8. Ejecutar el programa.
9. Para que funcione las puntuaciones el dispositivo móvil tiene que estar en la misma wifi que el ordenador.
