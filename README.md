1. Descargar el proyecto
2. Descargar Android Studio para poder lanzar la app.
3. Abrir el proyecto desde Android Studio.
4. Ejecutar el proyecto en Android Studio.
5. Si sale este error al Ejecutar el proyecto en Android Studio: SDK location not found. Define a valid SDK location with an ANDROID_HOME environment variable or by setting the sdk.dir path in your project's local properties file at 'C:\Users\"El nombre de tu usuario"\Desktop\RetroPlay\local.properties'.
Tienes que darle al icono de la hamburguesa (4 rayas) /File/Sync Project with Gradle Files. Para que se genere el archivo local.properties.
6. Las puntuaciones se envían a un servidor Replit. Para que se envíen las puntuaciones al servidor y se guarden en la base de datos tiene que estar el servidor levantado.
